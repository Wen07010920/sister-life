# 嫂子人生｜獨立手機網頁遊戲

## 本機測試
直接用瀏覽器開啟 `index.html`。若本機預覽不允許 JavaScript，請用下方免費託管方式。

## 免費部署到 GitHub Pages
1. 登入或建立 GitHub 帳號。
2. 建立新的公開 Repository，例如 `sister-life-game`。
3. 上傳本資料夾中的 `index.html`（可直接拖曳到 Repository 的 Add file / Upload files）。
4. 開啟 Repository 的 Settings → Pages。
5. 在 Build and deployment 選擇 `Deploy from a branch`；Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
6. 等待 GitHub Pages 部署完成，頁面會提供 `https://你的帳號.github.io/sister-life-game/` 類似網址。
7. 用 iPhone Safari 開啟該 HTTPS 網址即可遊玩。可以使用 Safari 的分享 → 加入主畫面，做成類似 App 的捷徑。

## 遊戲功能
- 手機優先深色社群介面與底部導覽列
- 劇情選項、親密度、曝光風險、網路熱度、公司信任
- theqoo / Instiz / Pann / X 虛構貼文切換
- 私訊互動、公司公關動態、粉絲派系觀測、事件紀錄
- localStorage 自動儲存、手動儲存、JSON 匯出／匯入存檔

所有人物私訊、論壇貼文與事件均為虛構同人模擬，不代表真實人物的私生活或真實發言。
